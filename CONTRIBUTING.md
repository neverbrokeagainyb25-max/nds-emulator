# Contributing

Thank you for your interest in contributing to the Nintendo DS Emulator!

This project is an open-source effort to build a Nintendo DS emulator in modern C++. Contributions, ideas, bug reports, documentation, and testing are all welcome.

## How You Can Help

There are many ways to contribute, including:

- Implementing CPU instructions
- Working on ARM9 emulation
- Working on ARM7 emulation
- Implementing the Nintendo DS memory system
- Working on cartridge support
- Developing graphics functionality
- Working on audio
- Implementing input and touchscreen support
- Improving performance
- Writing tests
- Improving documentation
- Reporting bugs
- Suggesting new features

You do not need to be an expert to contribute. If you're interested in learning about emulation or C++, feel free to explore the project and ask questions.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a new branch for your changes.
4. Make your changes.
5. Test your changes.
6. Commit your changes.
7. Open a pull request.

## Pull Requests

When opening a pull request, please:

- Explain what you changed.
- Explain why the change is needed.
- Include testing information when possible.
- Keep pull requests focused on a specific feature or fix.

## Issues

If you find a bug or have an idea for a feature, feel free to open an issue.

When reporting a bug, include:

- What happened
- What you expected to happen
- Steps to reproduce the problem
- Your operating system
- Your compiler and version, if relevant

## Code Style

This project uses modern C++.

Please try to:

- Write clear and readable code.
- Use descriptive names.
- Keep functions and classes focused.
- Avoid unnecessary complexity.
- Document complicated emulator or hardware behavior.

## Large Changes

For major architectural changes, please open an issue before beginning work. This gives the community a chance to discuss the design before significant work is done.

## Code of Conduct

Please be respectful and constructive when interacting with other contributors.

Everyone should feel welcome to participate, ask questions, and learn.

## Thank You!

Whether you're contributing code, reporting a bug, improving documentation, or simply testing the emulator, thank you for helping the project grow!

Let's build it together. 🚀
